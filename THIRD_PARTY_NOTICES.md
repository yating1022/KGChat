## Build and verification tooling

The production bundle has no third-party runtime scripts beyond the libraries
above. The production CSP is generated by a small local Vite plugin; static
hosting headers/fallback files (`public/_headers`, `public/_redirects`,
`vercel.json`) are project files.

Playwright is used only by the optional local QA script and is not a project
dependency or shipped asset. No fonts, images, or brand assets are hotlinked at
runtime; all brand paths are local SVG data.
